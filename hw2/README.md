# HW2


1. Нарисована диаграмма компонентов.
2. Нарисована диаграмма последовательностей.
3. Написан сервер на Python.

Сервер проверяет число:

- число должно быть от 0 до N;
- нельзя отправлять одно и то же число два раза;
- нельзя отправлять число, которое на один меньше последнего обработанного;
- при ошибке сервер возвращает ошибку и пишет её в терминал.


## Файлы

- app.py — сервер на Python.
- diagrams/components.drawio.png — диаграмма компонентов.
- diagrams/sequence.drawio.png — диаграмма последовательностей.
- compose.yaml — запуск PostgreSQL в Docker.
- Makefile — команды для запуска.

## Запуск

```sh
make install
make db-up
make run
```

`make db-up` ждёт, пока PostgreSQL полностью запустится.

После этого сервер работает по адресу:

```text
http://127.0.0.1:8000
```

Пример запроса из второго терминала:

```sh
curl -X POST http://127.0.0.1:8000/increment \
  -H 'Content-Type: application/json' \
  -d '{"number": 5}'
```
