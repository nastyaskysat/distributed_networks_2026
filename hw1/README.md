# HW1

Ачивка №1. "Параллельный" таймер AVR Assembler

Прошивка написана  на AVR Assembler для микроконтроллера ATmega8.

два независимых таймера:

- Первый через заданный интервал отправляет в UART строку `ping`.
- Второй через свой интервал отправляет строку `pong`.

Сделаны три уровня сложности:

1. Два таймера работают одновременно и выводят `ping\r\n` и `pong\r\n`.
2. Таймер работает с точностью до одного такта. Минимальная сумма интервалов для исходных строк: 3840 тактов (`T1 = 1920`, `T2 = 1920`).
3. Через UART можно менять интервалы, строки и перезапускать таймеры. Если настройка неправильная, программа выводит `ERR`.

## Команды UART

```text
T1=2880     изменить интервал первого таймера
T2=2880     изменить интервал второго таймера
R           перезапустить таймеры
S1=hello    изменить первую строку
S2=world    изменить вторую строку
