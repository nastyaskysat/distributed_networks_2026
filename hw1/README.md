# HW1

Программа для ATmega8 на AVR Assembler.

Запускает два таймера:

- первый отправляет в UART `ping`;
- второй отправляет в UART `pong`.

По умолчанию микроконтроллер работает на частоте 16 МГц, а UART настроен на
скорость 1 000 000 бод.


1. Два независимых таймера выводят `ping\r\n` и `pong\r\n`.
2. Таймер работает с точностью до одного такта. Минимальная сумма интервалов
   для исходных строк — 3840 тактов: `T1 = 1920`, `T2 = 1920`.
3. Через UART можно менять интервалы и строки, а также перезапускать таймеры.
   Неправильные значения не применяются, вместо этого выводится `ERR`.

## Команды UART

Команды нужно отправлять с новой строки.

```text
T1=2880     изменить интервал первого таймера
T2=2880     изменить интервал второго таймера
R           перезапустить таймеры
S1=hello    изменить первую строку
S2=world    изменить вторую строку
```

Строка может быть длиной до 6 символов. Для команд высокой сложности интервалы
должны быть не меньше 2880 тактов, иначе программа отправит `ERR`.

## Файлы

- `main.asm` — исходный код программы.
- `main.hex` — готовая прошивка для микроконтроллера.
- `validate.py` — проверка, что интервалы не мешают друг другу.
- `Makefile` — команды для сборки и проверки.

## Сборка

Нужно установить программы:

```sh
sudo apt update
sudo apt install avra avrdude gcc-avr avr-libc
```

Собрать прошивку:

```sh
make
```

Проверить интервалы:

```sh
make check
```

После сборки появляется файл `main.hex`. Его нужно прошить в ATmega8 через
программатор.

Пример для USBasp:

```sh
avrdude -p m8 -c usbasp -U flash:w:main.hex:i
```
